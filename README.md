# Dungeon Theory

A small front-end for the Dungeon Theory community site (React + Vite + TypeScript).

This repository contains a single-page site built with Vite and React. It includes a particle background canvas, responsive layout, and a number of presentational components.

## Prerequisites

- Node.js 18+ (or the version used in the project)
- npm (or your preferred package manager)

## Quick start

Install dependencies:

```bash
npm install
```

Start the dev server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

```bash
npm run dev
# if already running: Ctrl+C then npm run dev
```
